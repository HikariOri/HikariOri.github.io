## 骨骼链命名对照表

UE 5.8 的 IK Rig 自动命名本身就会搜索 `head / neck / hip / thigh / calf / knee / foot / ankle / toe / clavicle / shoulder / elbow / wrist / hand` 等常见骨骼词；VRM 也有一套标准化的人形骨骼结构；MMD 则大量使用日文骨骼名。([Epic Games Developers](https://dev.epicgames.com/documentation/unreal-engine/ik-rig-animation-retargeting-in-unreal-engine?lang=en-US&utm_source=chatgpt.com))

### 躯干与核心骨骼

| 中文   | English       | 日本語        | 常见骨骼名       |
| ------ | ------------- | ------------- | ---------------- |
| 根骨   | Root          | ルート        | `root`           |
| 骨盆   | Pelvis / Hips | 骨盤 / ヒップ | `pelvis`, `hips` |
| 中心   | Center        | センター      | `center`         |
| 下半身 | Lower Body    | 下半身        | `lower_body`     |
| 脊柱   | Spine         | 脊椎 / 背骨   | `spine`          |
| 上半身 | Upper Body    | 上半身        | `upper_body`     |
| 胸部   | Chest         | 胸            | `chest`          |
| 上胸   | Upper Chest   | 上胸          | `upper_chest`    |
| 颈部   | Neck          | 首 / 頸部     | `neck`           |
| 头部   | Head          | 頭            | `head`           |

其中：

`hips → spine → chest → upper chest → neck → head`

是非常常见的人形骨骼层级。VRM 官方的人形结构也是以 `hips` 为根，向上连接 `spine / chest / neck / head`。([VRM](https://vrm.dev/univrm/humanoid/humanoid_overview/?utm_source=chatgpt.com))

### 肩膀与手臂

| 中文 | English             | 日本語    | 常见骨骼名              |
| ---- | ------------------- | --------- | ----------------------- |
| 肩膀 | Shoulder            | 肩        | `shoulder`              |
| 锁骨 | Clavicle            | 鎖骨      | `clavicle`              |
| 上臂 | Upper Arm           | 上腕      | `upperarm`, `upper_arm` |
| 手臂 | Arm                 | 腕        | `arm`                   |
| 前臂 | Forearm / Lower Arm | 前腕      | `forearm`, `lowerarm`   |
| 肘部 | Elbow               | ひじ / 肘 | `elbow`                 |
| 手腕 | Wrist               | 手首      | `wrist`                 |
| 手   | Hand                | 手        | `hand`                  |

#### UE 里尤其要注意

Epic 的 IK Rig 自动识别会把：

```text
clavicle / shoulder
upperarm / arm
lowerarm
elbow
wrist
hand
```

视为手臂相关关键词。([Epic Games Developers](https://dev.epicgames.com/documentation/unreal-engine/ik-rig-animation-retargeting-in-unreal-engine?lang=en-US&utm_source=chatgpt.com))

典型 UE Mannequin 风格：

```text
clavicle_l
    └── upperarm_l
          └── lowerarm_l
                └── hand_l
```

而 VRM 则通常是：

```text
leftShoulder
    └── leftUpperArm
          └── leftLowerArm
                └── leftHand
```

不同格式之间可以直接对应起来。([みくだん](https://mikudan.blog.fc2.com/blog-entry-431.html?utm_source=chatgpt.com))

### 腿部

| 中文 | English                 | 日本語        | 常见骨骼名                       |
| ---- | ----------------------- | ------------- | -------------------------------- |
| 大腿 | Thigh / Upper Leg       | 太もも / 大腿 | `thigh`, `upperleg`, `upper_leg` |
| 腿   | Leg                     | 足 / 脚       | `leg`                            |
| 膝盖 | Knee                    | ひざ / 膝     | `knee`                           |
| 小腿 | Calf / Lower Leg / Shin | すね / 下腿   | `calf`, `lowerleg`, `shin`       |
| 脚踝 | Ankle                   | 足首          | `ankle`                          |
| 脚   | Foot                    | 足            | `foot`                           |
| 脚趾 | Toe / Toes              | つま先 / 足指 | `toe`, `toes`                    |
| 脚跟 | Heel                    | かかと / 踵   | `heel`                           |

最常见的腿部链：

```text
pelvis
 └── thigh
      └── calf
           └── foot
                └── toe
```

Blender Rigify 要求的标准腿部链也是：

```text
thigh → shin → foot → toe
```

并额外考虑 heel pivot。([Blender 文档](https://docs.blender.org/manual/ja/4.5/addons/rigging/rigify/rig_types/limbs.html?utm_source=chatgpt.com))

VRM 对应：

```text
hips
 └── leftUpperLeg
      └── leftLowerLeg
           └── leftFoot
                └── leftToes
```

([VRM](https://vrm.dev/en/vrm1/humanoid/?utm_source=chatgpt.com))

## 手指

这是做 Retargeting 时非常值得记的一组。

| 中文   | English               | 日本語   | 常见骨骼名        |
| ------ | --------------------- | -------- | ----------------- |
| 拇指   | Thumb                 | 親指     | `thumb`           |
| 食指   | Index Finger          | 人差し指 | `index`           |
| 中指   | Middle Finger         | 中指     | `middle`          |
| 无名指 | Ring Finger           | 薬指     | `ring`            |
| 小指   | Little / Pinky Finger | 小指     | `little`, `pinky` |

UE 5.8 IK Rig 本身就直接使用：

```text
thumb
index
middle
ring
pinky
```

来识别手指链。([Epic Games Developers](https://dev.epicgames.com/documentation/unreal-engine/ik-rig-animation-retargeting-in-unreal-engine?lang=en-US&utm_source=chatgpt.com))

### 手指的三节

人体手指通常从靠近手掌到指尖：

| 中文     | English               | 日本語 |
| -------- | --------------------- | ------ |
| 近节指骨 | Proximal              | 基節骨 |
| 中节指骨 | Intermediate / Middle | 中節骨 |
| 远节指骨 | Distal                | 末節骨 |

所以例如左食指可以是：

```text
leftIndexProximal
    └── leftIndexIntermediate
          └── leftIndexDistal
```

或者 UE 风格：

```text
index_01_l
    └── index_02_l
          └── index_03_l
```

VRM、Unity Humanoid 和 UE5 Mannequin 的对应关系正是这种结构。([みくだん](https://mikudan.blog.fc2.com/blog-entry-431.html?utm_source=chatgpt.com))

## Twist / 扭转骨

如果你开始做 UE 重定向，这组词也很重要。

| 中文     | English         | 日本語       |
| -------- | --------------- | ------------ |
| 扭转骨   | Twist Bone      | 捩じりボーン |
| 上臂扭转 | Upper Arm Twist | 上腕捩       |
| 前臂扭转 | Forearm Twist   | 前腕捩       |
| 手扭转   | Hand Twist      | 手捩         |
| 大腿扭转 | Thigh Twist     | 太もも捩     |
| 小腿扭转 | Calf Twist      | すね捩       |

MMD 中非常典型的就是：

```text
左腕捩
右腕捩
左手捩
右手捩
```

这类骨骼通常并不是“主要人体关节”，而是为了**改善网格变形、扭转分布**而添加的辅助骨骼。([note（ノート）](https://note.com/fantom1x/n/nca0bf10ce11f?utm_source=chatgpt.com))

## IK / 辅助骨骼

这部分和你最近 UE 5.8 的问题直接相关。

| 中文         | English                 | 日本語   | 典型用途     |
| ------------ | ----------------------- | -------- | ------------ |
| IK目标       | IK Goal                 | IKゴール | IK解算目标   |
| IK骨         | IK Bone                 | IKボーン | IK控制       |
| 左脚IK       | Left Foot IK            | 左足IK   | 脚部IK       |
| 右脚IK       | Right Foot IK           | 右足IK   | 脚部IK       |
| 左手IK       | Left Hand IK            | 左手IK   | 手部IK       |
| 右手IK       | Right Hand IK           | 右手IK   | 手部IK       |
| 膝部极向目标 | Knee Pole / Pole Vector | 膝Pole   | 控制膝盖朝向 |
| 肘部极向目标 | Elbow Pole              | 肘Pole   | 控制肘部朝向 |

注意一个很容易混淆的地方：

**`foot` 不等于 `foot IK`。**

例如：

```text
foot_l
```

通常是**真实变形骨骼**。

而：

```text
foot_ik_l
```

或者：

```text
LeftFootIK
```

通常是**控制/辅助骨骼**。

MMD 中也有明确的：

```text
左足ＩＫ
右足ＩＫ
左つま先ＩＫ
右つま先ＩＫ
```

这类 IK 骨骼。([Learn MikuMikuDance](https://learnmmd.com/http%3A/learnmmd.com/mmd-bone-reference-charts/?utm_source=chatgpt.com))

## 左右命名

这个基本是所有软件都通用的：

| 含义 | English    | 日本語          |
| ---- | ---------- | --------------- |
| 左   | Left / L   | 左              |
| 右   | Right / R  | 右              |
| 中央 | Center / C | 中央 / センター |

所以：

```text
leftUpperArm
rightUpperArm
```

对应：

```text
左上腕
右上腕
```

MMD 更直接：

```text
左腕
右腕
```

UE 则非常常见：

```text
upperarm_l
upperarm_r
```

UE 的 IK Rig 还会根据骨骼在角色左右侧的位置自动判断 `Left` / `Right` 链。([Epic Games Developers](https://dev.epicgames.com/documentation/unreal-engine/ik-rig-animation-retargeting-in-unreal-engine?lang=en-US&utm_source=chatgpt.com))

## 最值得你记住的一套“跨软件词汇表”

如果你的主要目标是 **UE + Blender + VRM + MMD + 动画重定向**，我建议把下面这一套直接当作自己的速查表：

| 中文   | English        | 日本語        |
| ------ | -------------- | ------------- |
| 根骨   | Root           | ルート        |
| 骨盆   | Pelvis / Hips  | 骨盤 / ヒップ |
| 脊柱   | Spine          | 脊椎          |
| 胸     | Chest          | 胸            |
| 颈     | Neck           | 首            |
| 头     | Head           | 頭            |
| 锁骨   | Clavicle       | 鎖骨          |
| 肩     | Shoulder       | 肩            |
| 上臂   | Upper Arm      | 上腕          |
| 前臂   | Forearm        | 前腕          |
| 肘     | Elbow          | ひじ          |
| 手腕   | Wrist          | 手首          |
| 手     | Hand           | 手            |
| 大腿   | Thigh          | 太もも        |
| 膝     | Knee           | ひざ          |
| 小腿   | Calf / Shin    | すね          |
| 脚踝   | Ankle          | 足首          |
| 脚     | Foot           | 足            |
| 脚趾   | Toe            | つま先        |
| 脚跟   | Heel           | かかと        |
| 拇指   | Thumb          | 親指          |
| 食指   | Index          | 人差し指      |
| 中指   | Middle         | 中指          |
| 无名指 | Ring           | 薬指          |
| 小指   | Pinky / Little | 小指          |
| 下巴   | Jaw            | 顎            |
| 眼睛   | Eye            | 目            |
| 舌头   | Tongue         | 舌            |
| 扭转   | Twist          | 捩            |
| IK目标 | IK Goal        | IKゴール      |

这套词基本可以覆盖你在 **UE Skeleton / IK Rig / Retargeter、Blender Armature、VRM Humanoid、MMD PMX** 之间来回转换时的大部分骨骼名称。UE、VRM、MMD 和 Blender 的实际命名并不完全一致，但它们的解剖结构对应关系非常稳定。([みくだん](https://mikudan.blog.fc2.com/blog-entry-431.html?utm_source=chatgpt.com))

还有一个很重要的细节：**`leg` 在不同软件里含义不一定相同**。例如 UE 的自动识别会把 `leg / hip / thigh / calf / knee / foot / ankle / toe` 都视为腿部相关关键词，而 VRM 明确使用 `UpperLeg → LowerLeg → Foot → Toes`。所以做 UE Retarget Chain 时，最好不要看到 `leg` 就机械地认为它等于“大腿骨”。([Epic Games Developers](https://dev.epicgames.com/documentation/unreal-engine/ik-rig-animation-retargeting-in-unreal-engine?lang=en-US&utm_source=chatgpt.com))
