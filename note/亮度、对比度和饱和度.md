这三个词经常被混用，但它们控制的是完全不同的东西：

| 参数              | 控制什么   | 直观感觉         |
| --------------- | ------ | ------------ |
| 亮度（Brightness）  | 整体明暗   | 像开灯或关灯       |
| 对比度（Contrast）   | 明暗差异大小 | 像把黑的更黑、白的更白  |
| 饱和度（Saturation） | 颜色鲜艳程度 | 像给颜色加颜料或抽掉颜色 |

([ToolsHubs][1])

---

## 1. 亮度（Brightness）

亮度决定图像有多亮。

假设有一个灰度值：

```
原来：
50 100 150 200
```

亮度 +50：

```
100 150 200 250
```

所有像素一起变亮。

可以理解成：

> 给每个像素加一个常数

数学上：

[
I' = I + b
]

其中：

* (I) 是原始亮度
* (b) 是亮度调整值

---

### 图形学里的理解

如果你写 Shader：

```glsl
color += 0.2;
```

本质上就是提高亮度。

---

## 2. 对比度（Contrast）

对比度控制：

> 最亮和最暗区域之间的差距有多大

([Study Rocket][2])

例如：

```
原图：

100 120 140 160
```

提高对比度：

```
60 100 180 220
```

亮的更亮：

```
160 -> 220
```

暗的更暗：

```
100 -> 60
```

于是层次感增强。

---

### 数学形式

通常围绕中灰（0.5）缩放：

[
I'=(I-0.5)C+0.5
]

其中：

* (C>1) 增加对比度
* (C<1) 降低对比度

---

### 图形学里的理解

如果你的 HDR 场景：

```
暗部 = 0.2
亮部 = 0.8
```

提高对比度后：

```
暗部 = 0.1
亮部 = 0.9
```

视觉冲击力更强。

很多游戏的 Color Grading 都会做这个。

---

## 3. 饱和度（Saturation）

饱和度控制：

> 颜色离灰色有多远

([shuttercoach.app][3])

例如：

高饱和红：

🟥

低饱和红：

🩷

零饱和：

⬜

---

### 举例

一个颜色：

```
RGB = (255,0,0)
```

这是纯红。

降低饱和度：

```
RGB = (180,80,80)
```

继续降低：

```
RGB = (128,128,128)
```

变成灰色。

---

### 图形学中的实现

先计算灰度：

[
Gray = dot(Color, Luma)
]

例如：

```glsl
float gray =
dot(color, vec3(0.299,0.587,0.114));
```

然后：

```glsl
color =
mix(vec3(gray), color, Saturation);
```

其中：

* Saturation=0

变灰

* Saturation=1

原图

* Saturation=2

颜色更鲜艳

# 三者一起看

假设原图是一朵花：

🌹

### 增加亮度

```
花还是红的
但整体更亮
```

像阳光变强。

---

### 增加对比度

```
阴影更黑
高光更亮
```

花更有立体感。

---

### 增加饱和度

```
红色更红
绿色更绿
```

花看起来更鲜艳。

# UE里的对应关系

在 Unreal 的 Post Process Volume 中：

* Exposure → 控制亮度
* Contrast → 控制对比度
* Saturation → 控制饱和度

实际上 UE 的 Color Grading 就是在调整这几个维度。

---

如果从图形学底层来看，可以把一个颜色看成 HSL/HSV 空间中的三个坐标：

* Hue（色相）—— 红、绿、蓝是什么颜色
* Saturation（饱和度）—— 颜色有多纯
* Lightness / Brightness（亮度）—— 有多亮

而对比度其实不是颜色本身的属性，而是**整张图像亮度分布的属性**。这也是为什么在图像处理中：

> 亮度 = 平移直方图
> 对比度 = 拉伸直方图
> 饱和度 = 调整颜色到灰轴的距离

这是最本质的理解方式。对于做 UE 渲染、Shader 或后处理的人来说，这个视角最有用。
