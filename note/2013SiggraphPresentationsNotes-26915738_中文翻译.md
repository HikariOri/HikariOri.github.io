## 引言

大约一年前，我们决定投入时间改进着色模型，并采用更具物理依据的材质工作流。驱动力一部分来自渲染更真实图像的愿望，另一部分来自我们希望借助更具物理依据的材质创建方式及材质分层达到的效果。艺术家认为这会极大改善工作流和品质；我此前也曾在另一家工作室亲历其益处，当时我们改用离线合成的材质层。Epic 的一位技术美术尝试在着色器中完成分层，结果很有前景，因此这也成为额外需求。

为支持这一方向，我们知道材质分层必须简单且高效。恰在此时，Disney 发表了关于其《无敌破坏王》所用物理着色和材质模型的报告 [2]。Brent Burley 表明，一组很小的材质参数就足以服务离线电影渲染；他也表明，一个相当实用的着色模型能很好拟合大多数采样材质。这项工作启发并奠定了我们的工作基础。类似他们的“原则”，我们为自己的系统定义了以下目标。

## 目标

- 实时性能：首先必须能高效地同时使用大量可见光源。
- 降低复杂度：参数应尽可能少。大量参数会带来决策瘫痪、反复试错，或相互关联的属性，以致一个预期效果要同时调整多个值。
- 一致性：必须能互换使用基于图像的光照和解析光源，因此参数在各种光源下都应表现一致。
- 直观界面：优先采用易于理解的数值，而非折射率等物理量。
- 感知线性：希望支持通过遮罩分层，但每像素只能负担一次着色。因此，参数混合后的着色结果应尽可能接近先着色再混合的结果。
- 易于掌握：避免要求用户理解绝缘体和导体，并尽量减少创建基本物理可信材质所需的工作。
- 鲁棒：应很难误建出物理上不可信的材质；所有参数组合都应尽可能稳健、可信。
- 表达力：延迟着色限制了可用着色模型数量，因此基础模型必须能覆盖现实世界中 99% 的材质。所有可分层材质也必须共享同一组参数，才可在它们之间混合。
- 灵活：其他项目和被授权方未必追求照片级真实感，因此系统也必须能支持非真实感渲染。

## 着色模型

### 漫反射 BRDF

我们评估了 Burley 的漫反射模型，但与 Lambert 漫反射（式 1）相比只看到很小差异，无法证明额外成本的合理性。更复杂的漫反射模型也难以高效用于基于图像的光照或球谐光照，因此我们没有投入太多精力评估其他选择。

```hlsl
f(l, v) = c_diff / π                                                (1)
```

其中 c_diff 为材质的漫反射反照率。

### 微表面镜面 BRDF

一般的 Cook-Torrance [5, 6] 微表面镜面着色模型为：

```hlsl
f(l, v) = D(h) F(v, h) G(l, v, h) / [4 (n · l) (n · v)]             (2)
```

本课程的 [9] 对此有详尽说明。我们以 Disney 的模型为起点，并把每个项与更高效的替代方案比较。实际工作比听起来困难，因为已发表公式对各项未必使用相同输入参数，而这对正确比较至关重要。

### 镜面项 D

对于法线分布函数（NDF），我们认为 Disney 采用的 GGX/Trowbridge-Reitz 非常值得其成本。相较 Blinn-Phong 的额外开销很小，而其更长的“尾部”所产生鲜明、自然的外观很受艺术家欢迎。我们也采用 Disney 的重参数化：α = Roughness²。

```hlsl
D(h) = α² / { π [ (n · h)² (α² − 1) + 1 ]² }                       (3)
```

### 镜面项 G

几何衰减项的候选方案最多。最终选用 Schlick 模型 [19]，并令 k = α/2，使其更贴合 GGX 的 Smith 模型 [21]。该修改令 Schlick 在 α = 1 时精确匹配 Smith，并在 [0, 1] 范围内形成很好的近似（图 2）。我们还采用 Disney 的修改：先把粗糙度重映射为 (Roughness + 1)²/8，再用于解析光源，以降低“过热”高光。注意该调整仅适用于解析光源；若用于 IBL，掠射角结果会过暗。

```hlsl
k = (Roughness + 1)² / 8
G₁(v) = (n · v) / [ (n · v)(1 − k) + k ]
G(l, v, h) = G₁(l) G₁(v)                                      (4)
```

### 镜面项 F

菲涅耳项采用通常的 Schlick 近似 [19]，但略作修改：用球面高斯近似 [10] 替代幂运算。它的计算略高效，且差异不可察觉：

```hlsl
F(v, h) = F₀ + (1 − F₀) 2^[(-5.55473(v·h) − 6.98316)(v·h)]        (5)
```

其中 F₀ 是正入射时的镜面反射率。

图 2：k = α/2 的 Schlick 与 Smith 的结果高度接近。

## 基于图像的光照

要将该着色模型用于基于图像的光照，须求解辐亮度积分，常以重要性采样完成。下式描述该数值积分：

```hlsl
∫H Lᵢ(l) f(l,v) cosθ_l dl ≈ (1/N) Σₖ [ Lᵢ(lₖ) f(lₖ,v) cosθ_lₖ / p(lₖ,v) ]   (6)
```

以下 HLSL 展示如何使用本着色模型。

```hlsl
float3 ImportanceSampleGGX(float2 Xi, float Roughness, float3 N)
{
    float a = Roughness * Roughness;
    float Phi = 2 * PI * Xi.x;
    float CosTheta = sqrt((1 - Xi.y) / (1 + (a*a - 1) * Xi.y));
    float SinTheta = sqrt(1 - CosTheta * CosTheta);
    float3 H = float3(SinTheta*cos(Phi), SinTheta*sin(Phi), CosTheta);
    float3 UpVector = abs(N.z) < 0.999 ? float3(0,0,1) : float3(1,0,0);
    float3 TangentX = normalize(cross(UpVector, N));
    float3 TangentY = cross(N, TangentX);
    return TangentX * H.x + TangentY * H.y + N * H.z; // 切线空间至世界空间
}
```

即便采用重要性采样，仍需大量样本。借助 mipmap [3] 可显著降低样本数，但要获得足够质量仍需超过 16 个样本。由于局部反射中每像素要混合许多环境贴图，实践中每张图只能负担一个样本。

### 分裂和近似

为实现这一目标，我们把上式拆为两个和，从而可分别预计算。对于常量 Lᵢ(l)，该近似是精确的；对于常见环境也相当准确。

```hlsl
(1/N) Σ [Lᵢ(lₖ) f(lₖ,v) cosθ / p(lₖ,v)] ≈ [(1/N)Σ Lᵢ(lₖ)] [(1/N)Σ f(lₖ,v)cosθ/p(lₖ,v)]  (7)
```

### 预过滤环境贴图

我们为不同粗糙度预计算第一个和，并将结果储存在立方体贴图的 mip 层中。这是游戏行业常用方法 [1, 9]。不同之处在于，我们以重要性采样按本着色模型的 GGX 分布卷积环境贴图。微表面模型的分布形状随观察角变化，因此假定该角为零，即 n = v = r。这个径向对称假定是第二个近似来源，意味着掠射角得不到拉长的反射。相对于分裂和近似，它实际是 IBL 解法中更大的误差来源。代码表明，按 cosθ_lk 加权会取得较佳结果。

```hlsl
float3 PrefilterEnvMap(float Roughness, float3 R)
{
    float3 N = R, V = R; float3 PrefilteredColor = 0; float TotalWeight = 0;
    for(uint i = 0; i < 1024; i++) {
        float3 H = ImportanceSampleGGX(Hammersley(i,1024), Roughness, N);
        float3 L = 2 * dot(V,H) * H - V; float NoL = saturate(dot(N,L));
        if(NoL > 0) { PrefilteredColor += EnvMap.SampleLevel(EnvMapSampler,L,0).rgb * NoL; TotalWeight += NoL; }
    }
    return PrefilteredColor / TotalWeight;
}
```

### 环境 BRDF

第二个和包含其余所有项，即以纯白环境积分镜面 BRDF（Lᵢ(lₖ)=1）。代入 Schlick 菲涅耳式后，F₀ 可以从积分中提出。这样只剩两个输入（Roughness 与 cosθ_v）和两个输出（F₀ 的 scale 与 bias），且都方便地位于 [0,1]。我们预计算该函数并储存于二维查找纹理（LUT）中。我们使用 R16G16 格式，因为精度很重要。

图 3：二维 LUT。图 4：上为参考结果，中为分裂和近似，下为含 n = v 假设的完整近似。径向对称假设带来最大误差，但组合近似仍很接近参考。图 5：使用绝缘体时的相同对比。

完成本工作后，我们发现已有和同期研究都导向几乎相同的方案。Gotanda 使用 3D LUT [8]；Drobot [7] 以近似相同方式将其优化为 2D LUT。本课程中 Lazarov [11] 更进一步，对相似积分给出若干解析近似。最终，将两个预计算的和相乘即可逼近重要性采样参考。

```hlsl
return PrefilteredColor * (SpecularColor * EnvBRDF.x + EnvBRDF.y);
```

## 材质模型

我们的材质模型是 Disney 模型的简化版本，着眼于实时渲染效率。限制参数数目对优化 G-Buffer 空间、降低纹理储存和访问、以及最小化像素着色器中材质层混合成本极为重要。基础材质模型如下：

- BaseColor（基础颜色）：单一颜色，概念更易理解。

- Metallic（金属度）：无需理解绝缘体和导体反射率，因此更不易出错。

- Roughness（粗糙度）：含义非常清楚，而 gloss（光泽度）总需要解释。

- Cavity（微腔）：用于小尺度阴影。

BaseColor、Metallic 和 Roughness 与 Disney 模型相同；Cavity 是新增参数。它描述运行时阴影系统无法处理的、较小几何体造成的阴影，通常是因为这些几何仅存在于法线贴图中，例如木地板板缝或衣物接缝。

最显著的删减是 Specular 参数。我们实际上一直使用它，直到完成 Infiltrator 演示，但最终并不喜欢它。“specular”这个名称很差，造成了许多混淆，也妨碍艺术家从控制镜面强度转向控制粗糙度。艺术家和图形程序员常忘记其范围，并以为默认值为 1，实际默认值为 Burley 的 0.5（对应 4% 反射率）。其有效用例几乎全是小尺度阴影。我们认为可变 IOR 对非金属并不重要，因此近期以更易理解的 Cavity 取代 Specular；非金属的 F₀ 现在固定为 0.04。

我们没有纳入基础材质模型、而作为特殊情况处理的 Disney 参数：Subsurface（以不同方式采样阴影贴图）、Anisotropy（需要大量 IBL 样本）、Clearcoat（需要双倍 IBL 样本）和 Sheen（Burley 笔记中定义不够明确）。除用于 Elemental 演示冰材质的 Subsurface 外，尚未在生产中使用这些特殊模型；另有一个专用于皮肤的着色模型。未来我们考虑混合延迟/前向着色，以更好支持专用模型。当前的纯延迟方案里，不同模型由储存在 G-Buffer 的模型 ID 通过动态分支处理。

### 经验

我多次看到一种情况：当我告诉刚开始使用可变粗糙度的艺术家“像过去使用 SpecularColor 那样使用 Roughness”，不久便会听到惊喜的“它可行！”随后有趣的评论是“Roughness 感觉反了”。艺术家希望自己绘制的纹理中，越亮的 texel 对应越亮的镜面高光；但若图像存的是粗糙度，越亮即越粗糙，反而得到强度更低的高光。

被问过无数次的问题是“Metallic 是二值的吗？”我原先会解释混合或分层材质的细微之处，后来发现最好只回答“是！”早期艺术家不愿把参数设为绝对值，常能发现 Metallic 为 0.8 的金属。材质分层应描述 99% Metallic 不为 0 或 1 的情形。过渡时，Fortnite 中一些材质无法复现：它的非真实感美术刻意给漫反射与镜面反射使用互补色，这不符合物理，也故意无法由新模型表达。经讨论，我们用引擎开关继续支持旧 DiffuseColor/SpecularColor，以维持当时已深度开发的 Fortnite 品质。但 Disney 在《无敌破坏王》中的使用证明新模型并不排斥非真实感渲染，因此未来项目仍会采用它。

## 材质分层

从共享库取得材质层并进行混合，相比旧的“为每个模型制作贴图并逐一指定材质参数”的方式有以下好处：可在多个资产间复用工作；降低单个资产的复杂度；统一并集中定义游戏外观的材质，更容易进行美术与技术指导。

为完全采用新工作流，我们重新思考了工具。UE 自 UE3 早期就有基于节点图的材质编辑器，节点图指定输入（纹理、常量）、操作和输出，并编译为着色器代码。令人意外的是，为支持材质层的创建与混合，工具端只需很少新增内容：UE4 编辑器中的节点图片段本已可归为函数并被多个材质调用，这自然适合实现材质层。把材质层留在节点编辑器中，而不是叠加一个固定函数系统，使图层可以可编程地映射和组合。

为简化工作流，我们添加了保存所有材质输出数据的 material attributes（材质属性）数据类型。它像其他类型一样，能够以一个引脚进出材质函数、沿连线传递并直接输出。这样，材质层可像从前的纹理一样拖入、混合、处理和输出。大多数材质图反而更简单，因为材质特有的主要内容变成层如何映射、如何混合，而不是过去针对每个参数的操作。

由于参数集合小且感知线性，完全在着色器内混合各层变得可行。我们认为这比纯离线合成系统带来大幅品质提升。通过以不同频率映射数据，纹理数据的表观分辨率可很高：逐顶点或低频纹理数据可以唯一；层混合遮罩、法线图和 cavity 图按网格指定；材质层在网格表面平铺；高级情形还会使用更多频率。尽管着色器成本限制了实际图层数，艺术家尚未认为它成问题。

值得关注的是，艺术家有时会把网格拆成多个 section 以绕过着色器内分层限制，导致更多 draw call。虽预期 UE4 的 CPU 端优化会改善 draw call 数量，这仍可能成为未来问题。我们尚未研究在某层覆盖率为 100% 区域通过动态分支降低着色器成本。迄今材质层体验极佳，生产效率和质量都有明显提升。我们希望改善材质层库的查找与预览界面，并在运行时系统之外研究离线合成/烘焙系统，以支持更多层和更佳可扩展性。

## 光照模型

和着色一样，我们希望让光照模型更具物理依据，重点是光衰减与非点状发射源（通常称为面积光）。改进光衰减相对直接：采用物理准确的平方反比衰减，并切换至流明这一光度亮度单位。但该函数没有衰减到零的距离；为使实时和离线计算高效，仍需人为限制光的影响范围。我们选择对平方反比函数做窗口化：保留绝大部分影响，同时平滑过渡为零。这样调整光半径不会改变其有效亮度，对美术已锁定、但仍须出于性能调整范围的光非常重要。

```hlsl
falloff = saturate(1 − (distance/lightRadius)^4)^2 / (distance² + 1)       (9)
```

分母中的 1 用来避免靠近光源时函数发散；在不追求物理正确的情况，它可以暴露为艺术家可控参数。这个简单改变带来的品质差异，尤其在有很多局部光源的场景中，可能是投入产出比最高的收获。

### 面积光

面积光不只生成更真实的图像；它对使用物理材质也很重要。我们发现，没有面积光时，艺术家会直觉地避免绘制很低的粗糙度，因为会产生无限小、看起来不自然的镜面高光；本质上，他们试图用点光源重现面积光效果。这令着色和光照耦合，破坏物理渲染的一条核心原则：材质不应因换了与创建时不同的光照环境而修改。

面积光仍是活跃研究领域。离线渲染通常从光源表面多个点采样 [12][20]，以均匀或重要性采样完成；这对实时渲染完全不可行。我们的要求是：漫反射 BRDF 和镜面 BRDF 计算的能量应一致；立体角趋近零时应趋近点光模型，不能因此丢失着色模型的特性；且必须快到可普遍使用，否则无法解决上述“偏置粗糙度”问题。

### 公告牌反射与锥体相交

公告牌反射 [13] 是可用于离散光源的一种 IBL：将储存发射光的二维图像映射到三维空间矩形，并如环境贴图预过滤般，为不同大小的镜面分布锥预过滤。镜面着色可视作锥体追踪；以近似镜面 NDF 的锥体中心光线与公告牌平面求交，用交点的图像空间坐标采样纹理，并据交点处的锥体半径选取 mip。图像虽可直观表达很复杂的面积光，却不满足第二项要求：平面上预过滤的图像只能表示有限立体角；光线不与平面相交时没有数据；着色模型需要的光向量 l 未知或被假设为反射向量。

锥体追踪也可解析完成而无需预过滤。我们试过用 Oat 的锥-锥相交方程 [15] 让锥与球相交，代价过高。Drobot [7] 的替代法是让锥与面朝着色点的圆盘相交，再对近似 NDF 的多项式在相交区域分段积分。这很有研究价值，但当前不满足需求：使用锥意味着镜面分布必须径向对称，因而无法得到微表面模型很重要的拉长高光；并且同公告牌反射一样，缺少已定义的光向量。

### 镜面 D 修改

我们去年提出过一种按光源立体角修改镜面分布的方法 [14]。其理论把光源分布视作对应锥角的 D(h)，把两个分布卷积近似为相加两个锥角，再转回新的 α，并以 α′ 替代 α：

```hlsl
α′ = saturate( α + sourceRadius / (3 * distance) )                         (10)
```

该技术很高效，但无法满足第一项要求：很光滑的材质在大型面积光下看起来会粗糙。若镜面 NDF 紧凑（如 Blinn-Phong），能更好匹配光源分布，效果会好得多；对于以 GGX 为基础的模型则不可行。

图 10：左为参考，右为镜面 D 修改。掠射角时球形丢失，抛光黄铜头等光滑材质看起来粗糙，近似质量不佳。

### 代表点

若对特定着色点，能把面积光的所有来光视作来自光源表面上的一个代表点，就可直接使用着色模型。合理选择是贡献最大的点；对 Phong 分布，即与反射光线夹角最小的光源点。此技术曾发表过 [16][22]，但没有处理能量守恒。移动发射光原点会有效增大光的立体角，却未补偿额外能量。校正不能简单除以立体角，因为能量差依赖镜面分布：粗糙材质改变入射方向带来的能量变化很小，光滑材质则可能极大。

### 球形光

若球位于地平线上方，球形光的辐照度与点光相同 [18]。这虽违背直觉，却意味着只要接受球沉入地平线时的误差，就只需处理镜面光照。我们以到反射光线距离最近的点近似与反射光线夹角最小的点：

```hlsl
centerToRay = L − (L · r) r
closestPoint = L + centerToRay * saturate(sourceRadius / |centerToRay|)
l = normalize(closestPoint)                                                    (11)
```

L 是从着色点到光心的向量，sourceRadius 是光球半径，r 是反射向量。光线与球相交时，该点是光线上最接近球心的点；归一化后与正确方向相同。把发射光原点移至球面，实际按球的张角拓宽了镜面分布。用归一化 Phong 分布可解释该变化；Ipoint 的半球积分为 1，而 Isphere 不再归一化，其积分可依幂 p 而大得多。

```hlsl
I_point = (p + 2)/(2π) cos^p φ_r
I_sphere = (p+2)/(2π),                 if φ_r < φ_s
         = (p+2)/(2π) cos^p(φ_r − φ_s),   if φ_r ≥ φ_s                  (12, 13)
```

为近似能量增加，我们沿用上文镜面 D 修改中按立体角拓宽分布的思路：以更宽分布的归一化因子替换原因子。GGX 的归一化因子为 1/(πα²)，代表点操作的近似归一化为：

```hlsl
SphereNormalization = (α / α′)²                                           (14)
```

代表点法满足全部要求：正确处理能量守恒后，材质行为不随光源尺寸而变；光滑材质仍产生边缘锐利的镜面高光；它只修改 BRDF 输入，因而不影响着色模型；并且足够高效，艺术家可随处使用。

图 11：式 13 所说明的拓宽效果可视化。图 12：左为参考，右为代表点法。能量守恒并非完美，但近似令人信服地匹配参考。

### 管形光

球形光适合表现灯泡；管形光（胶囊）适合表现现实中常见的荧光灯。先解决长度非零但半径为零的管形光，即线光。只要线段位于地平线上方，线段辐照度可解析积分 [16,17]：

```hlsl
∫(L₀→L₁) (n·L)/|L|³ dL = [n·L₀/|L₀| + n·L₁/|L₁|] / [|L₀||L₁| + (L₀·L₁)]   (15)
```

其中 L₀、L₁ 是从着色点到线段两端点的向量。我们修改该式以防止负辐照度、除零，并在长度为零时匹配点光衰减：

```hlsl
irradiance = 2 * saturate(n·L₀/(2|L₀|) + n·L₁/(2|L₁|)) / [|L₀||L₁| + (L₀·L₁) + 2]  (16)
```

线光镜面项需在 Ld = L₁ − L₀、l = normalize(L₀ + saturate(t)Ld) 中解 t。Picott [16] 给出使其与 r 夹角最小的 t；我们同球形光一样，以到反射线距离最短近似，得到更便宜且看似同样合理的：

```hlsl
t = [(r·L₀)(r·Ld) − (L₀·Ld)] / [|Ld|² − (r·Ld)²]                      (19)
```

存在未妥善处理的边界情况，所以该式不总能找到最近点，但计算略便宜，效果与原式同样合理。式 18、19 都把 r 当作直线而非射线，因此无法正确处理背离线段的射线；即使完全平坦的表面，也可能从一个端点突然跳到另一个端点。可以在计算点与两端点间选择以解决，但代价高，当前接受该伪影。

为守恒能量，对管形光采用球形光相同概念。镜面分布被光的张角拓宽，但仅在一个维度，因此使用 GGX 的各向异性版本 [2]。各向异性 GGX 的归一化因子为 1/(παxαy)，等向情形 αx=αy=α，因此：

```hlsl
LineNormalization = α / α′                                                 (20)
```

由于我们只改变光源原点并应用能量守恒项，这些操作可以累积。在线段上累积球形光，可较好近似形状卷积，从而模拟管形光的行为。代表点与能量守恒对简单形状有效；未来希望扩展至球与管外的形状，特别是带纹理的四边形，以表达更复杂、多色的光源。

## 结论

我们向更具物理依据的着色、材质和光照实现迁移，已证明非常成功。它显著提升了最新 Infiltrator 演示的视觉效果，并计划用于全部未来项目。事实上，在可行的情形下，这些改进已整合进在本工作开始前便已深入开发的 Fortnite。我们将继续改进，追求更高的灵活性和可扩展性，使各种场景和各档硬件都可受益于物理方法。
