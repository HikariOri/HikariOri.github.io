骨骼链命名对照表

UE 5.8 的 IK Rig 自动命名本身就会搜索 head / neck / hip / thigh / calf / knee / foot / ankle / toe / clavicle / shoulder / elbow / wrist / hand 等常见骨骼词；VRM 也有一套标准化的人形骨骼结构；MMD 则大量使用日文骨骼名。(Epic Games Developers)

躯干与核心骨骼

中文 English 日本語 常见骨骼名
根骨 Root ルート root
骨盆 Pelvis / Hips 骨盤 / ヒップ pelvis, hips
中心 Center センター center
下半身 Lower Body 下半身 lower_body
脊柱 Spine 脊椎 / 背骨 spine
上半身 Upper Body 上半身 upper_body
胸部 Chest 胸 chest
上胸 Upper Chest 上胸 upper_chest
颈部 Neck 首 / 頸部 neck
头部 Head 頭 head

其中：

hips → spine → chest → upper chest → neck → head

是非常常见的人形骨骼层级。VRM 官方的人形结构也是以 hips 为根，向上连接 spine / chest / neck / head。(VRM)

这套词基本可以覆盖你在 UE Skeleton / IK Rig / Retargeter、Blender Armature、VRM Humanoid、MMD PMX 之间来回转换时的大部分骨骼名称。UE、VRM、MMD 和 Blender 的实际命名并不完全一致，但它们的解剖结构对应关系非常稳定。(みくだん)

还有一个很重要的细节：leg 在不同软件里含义不一定相同。例如 UE 的自动识别会把 leg / hip / thigh / calf / knee / foot / ankle / toe 都视为腿部相关关键词，而 VRM 明确使用 UpperLeg → LowerLeg → Foot → Toes。所以做 UE Retarget Chain 时，最好不要看到 leg 就机械地认为它等于“大腿骨”。(Epic Games Developers)
